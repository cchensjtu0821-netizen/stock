# 阿里巴巴港股历史回放数据

标的 `hk09988`，币种HKD，价格为HKD/股，成交量为股。原始行情来自腾讯财经，分红日程来自新浪财经，均于2026-10-19抓取；逐请求URL、UTC抓取时间、HTTP状态和SHA256见 `raw/*.source.json`。原始响应按字节保存，处理后CSV截止2026-10-16，原始及前复权日期已核对一致。

- `processed/alibaba_hk_raw.csv`：未复权开高低收及成交量，用于成交。
- `processed/alibaba_hk_qfq.csv`：提供方前复权，用于公司行动核对。
- `processed/alibaba_hk_dividends.csv`：除息日、每10股现金金额、送转股字段。
- `quality.json`：分红来源、核验方法及未知信息；`manifest.json`：文件哈希。

行情范围为2023-01-03至2026-10-16，共933行；历史原始响应可能包含研究窗口之外的内容，回放只使用截至2026-10-16的数据。日历为行情提供方股票交易日，不跨A/H股日历前向填充。研究结果及指标信号位于 `research/additional_donchian/`。

腾讯港股日线成交量按股保留。分红港元金额通过未复权与前复权的差分变化提取，OHLC调整差已核验为纯现金形式；除净日与新浪独立分红日程一致。金额精度为每股0.001港元，是提供方现金除息调整代理；阿里美元股息的实际港元到账换汇价格未核实。主比较采用税前股息，另有20%股息税敏感性，不冒充用户个人税后收益。

港股使用独立10万港元现金账户口径，不折算人民币收益。每手100股，不套A股10%涨跌停；收盘信号次日开盘执行，未模拟日内交易或完整订单簿。佣金0.03%最低3港元、每笔平台费15港元为研究假设，真实券商费率未知；其他费率及生效日期见报告引用的港交所规定。

复现：`.venv/bin/python scripts/fetch_extended_stocks.py`（默认复用并校验缓存），随后执行 `.venv/bin/python scripts/replay_additional_donchian.py`。
