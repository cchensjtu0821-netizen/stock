# 紫金矿业三年研究数据

研究截止日为 2026-10-18，当日为周日；最后交易日为 2026-10-16。行情从 2023 年初开始保存，为 2023-10-18 起的三年回放提供预热历史。以下均为实际下载数据，非模拟数据。

`raw/` 保存腾讯按年度请求的 JSON、黄金交易所 JSON、申万 JSON 和新浪分红网页原文。此前测试请求保存的 `qq_*.json` 属于同源的额外快照，回放以 `processed/` 和清单为准。

[manifest.json](manifest.json) 记录接口地址、请求参数、覆盖范围、文件时间与 SHA256 校验值。该清单生成时间与各原始文件实际保存时间分别记录。申万首次公开数据请求在证书链验证失败后关闭校验取得，常规下载代码仍启用校验。东方财富接口测试失败后，板块口径已统一替换为申万指数，没有混合拼接两个指数。

三年区间有 726 个紫金交易日。申万原始发布序列缺少 2026-10-15，该日期和紧随其后的日收益不参与相关回归；当日也不允许依赖板块过滤的新开仓。没有为此缺口伪造或前向填充数据。黄金与股票交易日并非完全相同，计算关联时先按 A 股日期对齐价格，保证收益对应同一起止日期。

原始价格和前复权价格的日期完整对应；前向加回累计已除息现金股息后的收盘序列，与提供方前复权序列仅相差一个 1.85 元的常数，核对结果见 [data_quality.json](../../research/zijin/data_quality.json)。这项核对支持样本内分红和价格口径一致，不能代替对所有市场数据的独立审计。

运行 `scripts/fetch_zijin_data.py` 可以从缓存重建 CSV 和清单；运行 `scripts/replay_zijin.py` 会验证数据 SHA256 后计算。原始 API 和历史数据版本可能变化，应保留本目录快照来复现这次结果。
