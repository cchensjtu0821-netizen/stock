# 股票分析数据字段

输入分为交易日行情和财务快照。来源字段应填写数据提供方与可追溯链接或原始文件位置。程序不验证来源是否真实，导入前需要核查财务口径、币种与复权方式。

## 财务快照

每行代表一家公司在一个披露日期可获得的完整 TTM 快照。快照选择顺序为：排除 `published_date` 晚于研究日的行，选择财务期末最新的一行，同一期末再选择披露日期最新的版本。相同代码、期末和披露日不允许重复。

| 字段 | 要求与单位 |
| --- | --- |
| `symbol` | 必填，与行情代码完全一致。 |
| `period_end` | 必填，TTM 财务期末，YYYY-MM-DD。 |
| `published_date` | 必填，这一版本全部输入数据实际可得的最晚披露日期，YYYY-MM-DD，不能早于期末。 |
| `currency` | 必填，与行情相同，如 USD、CNY、HKD。没有自动汇率换算。 |
| `source` | 必填，财报原始链接或可追溯文件位置。多个文件可在单元格内列出。 |
| `revenue_ttm` | 最近连续四季度营收，基础货币单位。 |
| `revenue_prior_ttm` | 上年同期连续四季度营收，基础货币单位。 |
| `eps_ttm` | TTM 归属普通股股东稀释 EPS，货币 / 股。 |
| `eps_prior_ttm` | 上年同期 TTM 稀释 EPS，与当期使用一致的拆股口径。 |
| `net_income_ttm` | TTM 归属普通股股东净利润，基础货币单位。 |
| `average_equity` | 对应 TTM 的平均普通股权益，基础货币单位。可采用期初与期末均值，但所有比较对象必须一致。 |
| `operating_income_ttm` | TTM 营业利润，基础货币单位。 |
| `operating_cash_flow_ttm` | TTM 经营活动现金净流量，基础货币单位，可为负。 |
| `capex_ttm` | TTM 购建长期经营资产的资本开支现金流出，以非负金额填写。不要直接填现金流表上的负号。 |
| `shares_outstanding` | 快照已知的当期发行在外普通股总数，大于零；包含限售等发行在外股票、剔除库存股，不是自由流通股数或 EPS 使用的稀释加权平均股数。用于估计市值。 |
| `debt` | 财务期末有息债务，非负，基础货币单位；租赁是否计入需统一约定。 |
| `cash` | 财务期末现金及现金等价物，非负，基础货币单位。 |
| `ebitda_ttm` | TTM EBITDA，基础货币单位，调整项口径需一致。 |

所有数值字段可整列省略或留空，相关指标会显示 `N/A`。`NaN`、无穷大、带千分位的字符串和单位后缀均不接受；不要用零代表未知。

## 时间和口径

TTM 必须从独立季度构造；如果现金流数据是年初至今累计值，应先差分还原单季度，再合计连续四季度，避免重复累加。EPS 如有复杂的稀释分母变化，应优先核对可比的正式 TTM 数据，不要机械相加不同股本基础的 EPS。

更正财报应另增一行并保留实际更正披露日，不能用后来修订的数据覆盖更正前的历史快照。当前格式按整行记录可得性；若某个字段后续才可得，需生成一个新版本，或在旧版本中保留空值。

拆股或 ADR 比例变化后，股价、EPS 和股数必须统一到研究日对应的股份基础；历史时点研究也要保留当时基础。程序无法仅凭数值自动识别股本口径错误。财报披露后的回购、增发会使旧股数估计的当前市值产生偏差。

行情文件由提供方保证交易日完整；程序只检查重复日期、数值和币种，不会调用交易所日历识别漏行。缺少一行会改变固定行数窗口的实际跨度。相对收益要求股票最近 64 个日期在基准中全部存在，避免用不同起止点计算。

程序在行情距研究日超过 7 个自然日、财务期末超过 180 个自然日时提示检查更新。这两个值是数据维护提示，不是经过验证的投资信号。

## 数据接入顺序

第一步选定市场与行情提供方，确认复权、退市覆盖、延迟和使用权限。第二步获取公司正式财报，保留原始文件和抓取时间，映射成上述快照。第三步人工抽查若干股票及拆股、亏损、财报更正等特殊情况，再扩展股票池。

美股公司研究可从 [Investor.gov 的 10-K 阅读说明](https://www.investor.gov/introduction-investing/getting-started/researching-investments/how-read-10-k) 了解正式文件包含的信息。当前版本由使用者提供 CSV，尚未接入在线行情或自动财报映射。
